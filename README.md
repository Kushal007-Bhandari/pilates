# Align Pilates & Wellness Studio

Premium wellness center website for **Align Pilates & Wellness Studio** at A-Fit Studios, One Sky Building, Pulchowk, Lalitpur, Nepal.

- **Instagram:** [@align.byafitstudios](https://www.instagram.com/align.byafitstudios)
- **WhatsApp booking:** Schedule → book form → prefilled WhatsApp message

## Run locally

```bash
npm install
npm run dev
```

If the dev server shows errors after edits:

```bash
npm run dev:clean
```

## Content

Edit studio data, classes, schedule, FAQ, and gallery in `src/lib/data.ts`.

Paste Google Form URL into `studio.bookingFormUrl` when ready.
